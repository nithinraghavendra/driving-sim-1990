# 🚗 Java Car Simulator 1990

A simple car simulator built using Java, where you can start the car, switch gears, accelerate, brake, and exit through a menu.

This is one of my small practice projects while getting more comfortable with Java and programming fundamentals. Nothing too fancy, just experimenting with logic, loops, conditionals, and switch statements while learning how to make things actually work.

**Features**
- Start the car
- Select gears (P, D, R)
- Accelerate
- Brake
- Basic speed tracking
- Menu-driven interaction using a `switch` statement

Built as a learning project and a small step in my journey of getting better at programming, one project at a time.

**Tech:** Java
